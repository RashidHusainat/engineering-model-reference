# Change-Level Plans

Only significant/critical changes (Task Risk C/D) need a formal plan by default.
Use `specs/<change>/plan.md` with:

- Goal
- Scope / Out of Scope
- Relevant Source of Truth
- Business / Technical Impact
- Files / Modules affected
- Contracts affected
- Implementation steps
- Verification strategy
- Risks / Open questions

A/B work should not acquire ceremony just because this folder exists.
